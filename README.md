# To-Do List Dashboard

Website dashboard interaktif untuk mengelola tugas, kalender, target, dan catatan dalam satu tampilan.

## Fitur

- Sidebar navigasi untuk Dashboard, To Do List, Kalender, Progress, Target, dan Catatan
- Kalender interaktif dengan pilihan tanggal, bulan, dan tahun
- To Do List per tanggal yang bisa ditambah, dicentang, dan dihapus
- Progress otomatis berdasarkan tugas yang selesai
- Target dan Catatan yang bisa diedit langsung
- Tampilan responsif untuk desktop dan mobile

## Cara Menjalankan

1. Buka folder project
2. Jalankan server lokal, misalnya:
   ```bash
   python3 -m http.server 8000
   ```
3. Buka browser ke:
   ```text
   http://127.0.0.1:8000/
   ```

## Struktur File

- index.html: struktur halaman utama
- styles.css: desain dan layout dashboard
- script.js: logika interaktif seperti kalender, tugas, dan editan
